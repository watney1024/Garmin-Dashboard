# 周报复盘 · 示例（虚构跑者"示例跑者"）

> 复盘范围：上一个周一到周日；默认每周一执行。

## 复盘四段式模板

1. **上周实际 vs 计划** — 逐课对照：完成 / 未完成 / 临时改了什么（引用偏差原因）
2. **三条趋势** — 周跑量 · 长距离完成度 · **E 跑心率漂移**（同配速下心率变化）
3. **风险判定** — 绿 / 黄 / 红 + 触发的具体规则
4. **下周调整清单** — 改了哪几课、为什么

**④ 下周调整清单**：无结构改动。注意观察周四心率是否回落；若不回落再议。
