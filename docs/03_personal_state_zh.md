# 03 · 个人状态：主观数据与安全基线（写给 AI agent）

训练状态的判断 = **客观数据（Garmin，docs/02）+ 主观反馈（跑者一句话）+ 一套定死的判定规则**。
主观部分的价值在于抓客观数据抓不到的早期信号：静息心率、睡眠、伤病感觉、疲劳。**伤病信号行优先级最高。**

## 1. 跑者每周唯一要做的事：一句话

> 模板：`日期(方向) + 星期 + 课名 + 完成情况 + 哪先累 + 偏差原因`
> 示例：`8/10 周二 E5，完成。气先累，腿还行。`

- **哪先累**是最关键的主观感受：`腿先不行`＝外周疲劳（肌肉/肌腱），`气先不行`＝中枢/心肺疲劳。两者处理方向不同。
- **偏差原因**帮 agent 区分「**主动减量**」（合理，按计划调整即可）和「**被动掉量**」（工作/生病/伤病导致，要警惕并检查下周安排）。
- 伤病信号可以**单独随时说**（四部位 0–10，单侧且 ≥5 必须立刻说，不要等周一）。

## 2. 主观 6 项（写入训练日志的每周一节，agent 代填）

精确格式，逐字照抄：

```
## W__　__/__ – __/__
- 晨起静息心率（周均）：__ bpm
- 体重（周均）：__ kg
- 睡眠（周均）：__ h
- 整体疲劳 RPE：__ /10
- 伤病信号 0–10（0=无感）：小腿前侧 __ / 跟腱 __ / 膝盖 __ / 足底 __
- 跑量偏差原因：
- 备注：
```

### 字段锚点（判定标准，写死）

| 字段 | 怎么测/怎么读 | 触发点 |
|---|---|---|
| 晨起静息心率 | 早晨**未起床前**看手表（每日）；记周均 | 比跑者基线 **高 +8 bpm**：**连续 1 天 ⇒ 🟡 黄灯**（观察 ＋ 黄灯动作）；**连续 2 天 ⇒ 🔴 红灯，但动作仅为"当天改休息"**（**不套用**红灯默认的"停跑 3 天"），并同时按黄灯触发当周调整（docs/06） |
| 体重 | 晨起空腹，记周均 | 不作为硬规则；剧烈波动（>±2 kg 且无解释）提示水肿/脱水/食欲问题，需询问 |
| 睡眠 | 周均小时数 | <5h 连续多日或明显低于个人常态 ⇒ 降低当周强度课负荷 |
| RPE | 整周疲劳感 1=很轻松 10=精疲力竭 | **连续两周 ≥8** ⇒ agent 主动减量 |
| 伤病信号 | 四部位分开打分：`0` 无感 · `3` 有感觉但不影响跑 · `5` 影响跑姿/被迫减速 · `7+` 停跑 | 任一部位 **3–4** ⇒ 黄灯；任一部位 **≥5** ⇒ 红灯；**单侧出现且 ≥5** ⇒ 红灯，立即行动，不讨论 |
| 跑量偏差原因 | 一句话 | 用于区分主动减量 vs 被动掉量 |
| 备注 | 自由 | 比赛结果、特殊情况等 |

**四部位：小腿前侧（胫骨） / 跟腱 / 膝盖 / 足底。** 缺测部位写 `_`，缺整行数据写"主观数据缺失"。

## 3. 为什么要盯"单侧"

双侧对称的酸痛是疲劳，休息即可；**单侧的痛是结构性问题**——胫骨应力反应、跟腱病变、髂胫束综合征都从单侧发作。这条规则跑者不自判，agent 看到单侧且 ≥5 直接按红灯行动。

## 4. 默认安全基线（黄/红灯，先定死不每周争论）

训练计划应包含这样一张表（具体动作见 docs/06；教练包只能加严不能放宽）：

| 等级 | 触发条件（任一） | 自动动作 |
|---|---|---|
| 🟡 黄灯 | 静息心率比常态高 **8 bpm** 以上**连续 1 天**；任一部位伤病 **3–4**；周跑量完成 **<80%**；连续两周 RPE≥8 | 砍掉本周恢复性质的轻松跑；长距离 **降 20%**；当周不安排提速段 |
| 🔴 红灯 | **静息心率连续 2 天比常态高 8 bpm 以上**；任一部位伤病 **≥5**；出现**单侧**的痛（最关键）；连续两周完成 **<70%** | 伤病/完成度类：**停跑 3 天**；**静息心率类：当天改休息**（**不套用**停跑 3 天）；目标降档；力量课保留（下肢减半）；恢复后从当前周重新起跑，**不补量** |

**静息心率 +8 bpm 分两级**（这是唯一一条"红灯但不等于停跑"的规则）：**连续 1 天 ＝ 🟡**，
**连续 2 天 ＝ 🔴 且动作只是"当天改休息"**——不要顺手套用红灯默认的"停跑 3 天"。

**红黄灯判定必须引用触发的具体规则**，例如：`红灯：左跟腱伤病评分 5，单侧`。

## 5. 缺数据的处理

- 某一项没报 → 该项写"主观数据缺失"，**绝不编造或猜**。
- 只有客观数据能算的（跑量完成度、E 跑心率漂移）照常算。
- 伤病信号缺失且无法确认时，倾向保守（宁可多休一天）。

## 6. 什么时候 agent 主动问跑者

- 客观数据出现异常但主观没报（跑量骤降/骤升、心率趋势异常）。
- 非 A 赛/测试赛后（要成绩填进 runner profile 的 PR 以更新 VDOT）。
- 触发黄灯但跑者一句话里没给偏差原因。
