# 07 · 跑者手册：你只负责两件事（给人类跑者）

这份手册是**给你（跑者）看**的。agent 做的事你不用学、不用管；你只需要：

1. 每周（或想报时）说**一句话**身体状态。
2. 维护自己的 `runner_profile.yaml`（赛历/可用日/PR 有变化时改）。

## 1. 每周一句话

格式照抄填空：

> `8/10 周二 E5，完成。气先累，腿还行。`
> 六要素：日期(方向) + 星期 + 课名 + 完成情况 + 哪先累 + 偏差原因。

- **哪先累**最重要：`腿先不行`=腿累，`气先不行`=心肺累。
- **偏差原因**写不写决定 agent 判断"主动减量（没事）"还是"被动掉量（要管）"。
- 伤病**单独说也行，不用等周一**，尤其：单侧痛且 ≥5（0–10）→ 立刻说。
- 数据（主表＋每次明细）全自动拉取：**你不导 CSV、不丢文件、不改名。**

## 2. 常见请求怎么发

| 你想知道/想要 | 发什么 | 结果 |
|---|---|---|
| 生成/重排计划（换目标/换教练） | `prompts/generate_plan` | 新 HTML 计划（含赛历/A 赛/配速/闸门/版本） |
| 每周更新（默认周一自动） | `prompts/weekly_update` | 日志+复盘+判灯+改计划+≤400 字总结 |
| 这周练什么 | `prompts/current_week_schedule` | 当周 7 天课表与关键课注意点 |
| 把课表排进手表 | `prompts/schedule_to_watch` | Garmin 日历出现当天课，记得同步手表 |

具体文字见 `prompts/` 目录；把 `<占位>` 换成你的实际文件路径/档案即可。

## 3. 什么时候看计划、什么时候不用看

- **每天**：起床看手表静息心率；出门训练前瞄一眼当天课名即可。
- **周一**：说一句话；然后随便扫一眼 agent 的 ≤400 字总结（颜色 + 下周改动）。
- 黄/红灯被触发时，按总结里的动作执行即可，不用自己研究该跑多少。
- 觉得不舒服、怀疑伤病 → 直接说，让 agent 判，别硬跑。

## 4. 比赛怎么对待

- 只有一个 A 赛要全力；**其他比赛只是训练/尝试**（role 见档案），跑法听计划的。
- A 赛后：告诉 agent 成绩，它会更新 PR 与 VDOT、安排赛后恢复。

## 5. 你需要遵守的三条红线

1. **单侧持续/夜间/跑中加重的痛** → 停 48 小时，别"跑开了就好"。
2. 静息心率连续 2 天比平时高 8 以上 → 那天休息。
3. 想临时改计划 → 改之前说一声（让 agent 判断是否会影响 A 赛）。

## 6. 重要提醒

- **跑不完不是问题，不报才是。** 哪怕只跑了一半也照实说。
- 配速/心率的细节 agent 会看数据，你只负责"身体感觉"这半边。
- 本仓库的教练包/VDOT 配速均为通用概括或近似值，若有医学/伤病疑问请咨询医生。
