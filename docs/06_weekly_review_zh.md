# 06 · 每周复盘：闭环与判灯（写给 AI agent）

复盘是计划能"活"的关键：**每完成一周，把客观数据 + 主观一句话变成（a）记录（b）判定
（c）下一周调整**。默认节奏：每周一复盘**上一个周一到周日**；跑者也可随时触发。

输入：重建后的 `Activities.csv` + `inbox/activity_<id>.csv`（新下载）+ 跑者一句话 +
`runner_profile.yaml` + 计划 HTML。

## 1. 复盘步骤（固定顺序）

1. 刷新客观数据（有 MCP 工具则拉取，见 docs/01；否则注明数据截止日期）。
2. 匹配本周活动（按活动 ID），算周跑量/完成度；补下载缺失明细。若教练包用点数（如 daniels_vdot），逐活动算**强度点数**并汇总周分（口径与失真处理见 docs/09 §7：移动时长；走跑结合课封顶、间歇课按计划分数记账）。
3. 把主观 6 项填进训练日志对应 W 节（docs/03 §2；缺写"主观数据缺失"，伤病行优先）。
4. 按下面 §2 出复盘四段式，追加到周报复盘滚动文档。
5. 判灯（§3）并按需**改计划**（§5）。
6. 更新顶部闸门进度表（§4）。
7. 回复跑者 ≤400 字：上周跑量/完成度、风险颜色、下周改了什么、需要我注意的一件事。

## 2. 复盘四段式模板（每节照抄）

```
① 上周实际 vs 计划 — 逐课对照：完成 / 未完成 / 临时改了什么（引用偏差原因）
② 三条趋势 — 周跑量 · 长距离完成度 · E 跑同配速心率漂移（计分制教练包加第 4 条：周负荷分 · 计划 N vs 实际 M）
③ 风险判定 — 绿 / 黄 / 红 + 触发的具体规则
④ 下周调整清单 — 改了哪几课、为什么
```

- **E 跑心率漂移**＝同配速下心率趋势：漂高说明恢复不够/状态下滑，漂低是适应良好。
- 非 A 赛/测试赛周：把"比赛跑法"当作当周长距离课来对照（training 不全力、attempt 认真、
  A 全力），并记录成绩。

## 3. 判灯（通用安全层，先定死不争论）

| 等级 | 触发（任一） | 自动动作 |
|---|---|---|
| 🟡 黄灯 | 静息心率连续 2 天比基线 **+8 bpm**；任一部位伤病 **3–4**；周跑量完成 **<80%**；连续两周 RPE≥8 | 砍本周轻松/恢复跑；长距离 **降 20%**；当周不安排提速段 |
| 🔴 红灯 | 任一部位伤病 **≥5**；**单侧**痛（最关键）；连续两周完成 **<70%** | **停跑 3 天**；目标降档；力量保留（下肢减半）；恢复后从当前周重新起跑，**不补量** |

- 双侧酸痛=疲劳可跑；**单侧痛=结构性问题，跑者不自判**（docs/03 §3）。
- 教练包红线只加严不放松；判定必须**引用规则**（如 `黄灯：左跟腱 3`）。
- 强度点数（docs/09 §7）是**建议性**指标：只用于趋势观察与教练包内的量调节，
  不触发、也不放宽任何黄/红灯。
- 与计划第十章/教练包闸门冲突时：取更严、且不违反安全层。

## 4. 闸门进度表

计划第七章的闸门落地为具体日期；复盘时把结果填进表：

| 闸门 | 日期/周 | 内容 | 门槛 | 实际 | 判定 |
|---|---|---|---|---|---|
| 1 | ... | 结构耐受（双硬日周后无异常酸痛/心率） | 见计划 | — | 待定 |
| 2 | ... | 测试赛换算目标（10K/半马） | 见计划 | — | 待定 |
| 3 | ... | 峰值长距离/30km 级达标 | 见计划 | — | 待定 |

**闸门 3（峰值长距离）= 一票否决**：无论测试赛多快，长距离不达标 → 比赛日保守起跑。
若该 A 赛没有对应测试，则由教练包/档案生成等效闸门。

## 5. 改计划机制（判黄/红或闸门结果后）

1. 编辑计划 HTML 的逐周课表相关行（下周/后续周）。
2. 更新 `canvas id="trk"` 的实际值数组（随周填充实际跑量）。
3. `版本记录`追加 `vN` 行：改了什么 + 触发原因；递增不跳号。
4. 若比赛成绩更新了 PR → 同步 `runner_profile.yaml` 并重算 VDOT（docs/08/09）。

## 6. 非 A 赛与赛后周处理

- **比赛前一周**：按计划 taper（教练包规则）；把比赛当作当周"长距离课"。
- **比赛后**：
  - A 赛：赛后一周降量（约 50–60%），记录成绩 → 决定下一个周期/休息计划。
  - attempt 赛且超 PR：按 docs/08 §2 更新 PR；成绩不进 PR 的也照实记录。
  - training 赛：当作完成了一堂质量课，正常推进。
- **掉量处理**：主动减量（出差/生病后减）→ 恢复正常即可，不补；被动掉量连续两周 → 按黄灯行动。

## 7. 红黄灯的边界

- 触发即行动，**不因"这周本来就轻"而跳过**——但已在计划里的恢复周照常执行（其本身已满足黄灯动作）。
- 教练包有更严的闸门/红线 → 用更严。
- 红黄灯表允许在跑者档案 `constraints` 中按个体情况**预先细化**（如特定旧伤部位更早触发），但不得放宽默认值。
